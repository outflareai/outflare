# Error code data

The full messages of the errors React, Redux and Redux Toolkit shorten to a
code in production builds ("Minified React error #418"), so an error can be
read without following its link. The same for every workspace; nothing a
workspace sends changes these files.

| File | Source | Licence | Refresh |
| --- | --- | --- | --- |
| `react.json` | [facebook/react](https://github.com/facebook/react) `scripts/error-codes/codes.json` | MIT (`react.LICENSE`) | Download the file over this one |
| `redux.json` | [reduxjs/redux](https://github.com/reduxjs/redux) `errors.json` | MIT (`redux.LICENSE`) | Download the file over this one |
| `redux-toolkit.json` | [reduxjs/redux-toolkit](https://github.com/reduxjs/redux-toolkit) `errors.json` | MIT (`redux-toolkit.LICENSE`) | Download the file over this one |

A code a file doesn't know is left as it was sent. Before adding a list,
check its licence allows commercial use and redistribution, and add a row
here.
